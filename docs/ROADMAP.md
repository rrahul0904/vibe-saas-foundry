# Roadmap

## Phase 0 — complete
Reference product across API, web, admin, marketing and Flutter; Docker, CI and agent docs.

## Phase 1A — complete
Password recovery, transactional email, safe token handling, throttling, Helmet, operator auth/RBAC, audit log, migration-first startup, tests and CodeQL.

## Phase 1B — advanced identity
OAuth/OIDC, TOTP/WebAuthn MFA, recovery codes and device/session inventory.

## Phase 2A — multi-tenancy/RBAC implemented
Organizations, personal-workspace migration, owner/admin/member memberships, email invitations, invitation acceptance/revocation, role safeguards, internal entitlement records, member limits, tenant-scoped task data, web workspace/team UI and mobile tenant context.

## Phase 2B — billing next
Stripe product/price mapping, checkout, customer portal, subscription webhooks, idempotency, plan transitions and entitlement synchronization.

## Phase 3 — platform capabilities
Background jobs, transactional outbox, notifications, object storage, webhooks, API keys, feature flags, analytics, structured logs/metrics/traces.

## Phase 4 — agentic foundry
Domain recipe engine, product-spec compiler, coding-agent work packets, previews, QA/evaluation agents and architecture drift checks.

## Phase 5 — generator
Web configurator that composes modules and generates a production-ready repository.
