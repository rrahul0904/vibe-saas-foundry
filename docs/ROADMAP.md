# Roadmap

## Phase 0 — implemented
Reference domain, auth, revocable sessions, web, admin, marketing, Flutter reference client, Docker, CI and agent-readable docs.

## Phase 1A — identity hardening implemented
Password reset, verification resend, transactional email adapter, production-safe token handling, rate limiting, Helmet, migration-first startup, persisted operator role, operator-authenticated admin console, audit log and targeted security tests.

## Phase 1B — advanced identity next
OAuth/OIDC account linking, TOTP/WebAuthn MFA, recovery codes, device/session inventory and stronger operator policy.

## Phase 2 — SaaS platform
Organizations, memberships, invitations, RBAC, Stripe plans, subscriptions, entitlements, customer billing portal.

## Phase 3 — platform capabilities
Background jobs, notifications, object storage, webhooks, API keys, feature flags, product analytics and tracing.

## Phase 4 — agentic foundry
Domain recipe engine, product-spec compiler, coding-agent work packets, automated preview environments, QA/evaluation agents, architecture drift checks.

## Phase 5 — generator
Web configurator that composes identity, billing, platforms, infrastructure and AI modules into a generated repository.
